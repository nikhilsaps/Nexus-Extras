Nexus LocalServe API

Live, self-contained reference for the Cardputer HTTP server. Serve this folder from the device and every panel below talks to the real API.

Base URL is this page's own origin (). The server lives in localserve.cpp; it streams files from the microSD (/sdcard/sites) and never buffers a whole file in RAM. Five routes exist; each is documented and runnable below.

GET/api/stat live heap, JSON

Returns the device's free-RAM snapshot. Poll it to watch memory while sites load.

Response

{ "free": 123456, "min_free": 90112, "largest_block": 65536 }
field meaning
free current free internal heap (bytes)
min_free lowest free heap seen since boot
largest_block biggest single allocatable block

        GET/api/sniff.json
        Wi-Fi sniffer results
      
      

        

          Snapshot of the passive Wi-Fi sniffer's device table. Only meaningful
          while the Sniff tool has been running; otherwise the list is
          empty. CORS is open (Access-Control-Allow-Origin: *) so
          external dashboards can read it.
        

        
Response

        
{
  "ch": 6, "frames": 10423, "devices": 2,
  "list": [
    { "mac":"a1:b2:c3:d4:e5:f6", "ssid":"CoffeeWiFi", "rssi":-61,
      "ch":6, "type":"AP", "count":210, "age":3 }
  ]
}

        

          

            field
            meaning
          

          

            ch
            channel the sniffer is parked on
          

          

            frames
            total frames seen this session
          

          

            type
            AP / STA / etc. per row
          

          

            age
            seconds since that device was last heard

        GETPOST
        /api/fetch
        HTTPS proxy
      
      

        

          The device fetches an upstream URL (its TLS bundle is built in) and
          streams the body straight back. Useful to pull the open internet into
          a page the Cardputer is hosting. The URL must start with
          http:// or https://. Needs the device to be
          joined to a network with uplink.
        

        
Query parameters

        

          

            key
            required
            meaning
          

          

            url
            yes
            upstream URL (URL-encode it)
          

          

            ref
            no
            Referer header to send upstream
          

          

            ua
            no
            User-Agent override
          

        

        

          Errors: 400 missing/bad url, 502 upstream
          connect failed.

        PUTPOST
        /api/save/<path>
        whole-file write to SD
      
      

        

          The raw request body becomes the file at
          /sdcard/sites/<path>. Last-write-wins; the server
          writes a temp file then renames it into place, so a failed save leaves
          the old file intact. It never parses the body, so save anything (HTML,
          JSON, binary).
        

        
Rules & limits

        

          

            SAVE_MAX
            body ≤ 4 MiB, else 413
          

          

            path
            
              no .., no \, no control bytes, no
              reserved .nexus-tmp/.nexus-bak sidecars → else
              400
            
          

          

            409
            
              a save to the same path is already in flight, or a backup sidecar
              from an interrupted save is still on the card

        GET/<anything>
        static file serving
      
      

        

          Everything not under /api/ is served as a file from
          /sdcard/sites. A request for /foo/ looks for
          /foo/index.html. If a .gz twin exists and
          the browser accepts gzip, the compressed copy is sent. Content-Type is
          set from the file extension. Missing root → a built-in
          "LocalServe is up" page; any other miss → 404.
