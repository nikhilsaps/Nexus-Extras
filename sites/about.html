About Nexus LocalServe

You are reading a page served straight off a microSD card by a Nexus Cardputer (ESP32-S3). No cloud, no PC: the little terminal joined your WiFi and started a web server.

How it works

Files live in /sites on the SD card. The firmware serves them by file extension, streams big files in chunks, and prefers a pre-compressed .gz twin when one exists. The launcher reads metadata.json to list what is hosted.

Add your own

Drop any static site into /sites and add an entry to metadata.json. Sub-folders work too, as long as you link to an explicit file like /notes/index.html (the server does not auto-index folders).
